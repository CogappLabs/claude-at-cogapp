## Tips

<TwoCol>
<div>

**Habits**

1. **Be specific**: give files, errors, expectations
2. **Iterate**: say what's wrong; don't restart
3. **Read what it writes**
4. **Start small**: bug fix before new feature
5. **Unsure it can do a thing? Ask it**

</div>
<div>

**Ergonomics**

- **Paste images**: broken UI, design comps, error dialogs
- **Escape** interrupts; **double Escape** edits an earlier message
- **`@file`**: mention files/folders directly
- **`! command`**: run shell yourself, output lands in conversation

</div>
</TwoCol>
