## Subagents & parallel work

Main agent spawns subagents that work in their own context, report back a result.

Built-in:
- **Explore**: file lookup, grep, single-file Q&A
- **general-purpose**: open-ended research, multi-step tasks

- Run independent work in parallel: faster, and each subagent's context stays out of the main thread.
- Define your own subagents for recurring jobs (review, debug).
